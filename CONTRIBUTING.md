# Contributing

1. Read AGENTS.md and docs/ARCHITECTURE.md.
2. Write the failing test first. Keep changes small.
3. A feature is done only when it works on **both** platforms (see Definition of done in AGENTS.md and docs/PARITY.md).
4. Run `make test` and `make docs-check` (and `make e2e` for UI changes) before opening a PR.
5. Conventional commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
6. Never commit secrets. See SECURITY.md.
