# Installing on phones (after the lab gate)

Android: enable developer options, USB debugging, `adb install` the release-like APK. iOS: Xcode > Settings > Accounts (free Personal Team), connect iPhone, enable Developer Mode, Run, trust the developer. Free-team builds expire after 7 days; limits: 3 devices, 10 App IDs, 3 apps per device. Debug builds point to the Mac LAN IP; release points to the deployed host.
