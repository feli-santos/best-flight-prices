# Glossary

**Band** Great/Good/Mixed/Avoid month label. **Explore** origin-only world search. **Scope** place, country, continent or popular. **Gateway** airport/city code used for fares. **ReasonCode** server enum rendered as localized text. **Lab** local emulation setup. **Cached fare** price seen recently by provider users, not live. **Parity** identical behavior on both platforms.
